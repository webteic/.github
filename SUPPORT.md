# Webteic Support

Webteic is an open-source project supported by its maintainers and community.

## Getting help

Before requesting help, please:

1. Read the Webteic documentation: https://webteic.com/docs/home
2. Search existing community discussions.
3. Check that you are using a supported Webteic release and server environment.

For community support, visit:

https://github.com/orgs/webteic/discussions

Use **Help & Support** for general questions or **Installation & Hosting** for installer, PHP, database and server-related problems.

## Information to include

When requesting help, please provide:

* Your Webteic version
* PHP and database versions
* The relevant module or feature
* What you expected to happen
* What happened instead
* Steps needed to reproduce the problem
* Relevant error messages, logs or screenshots

Remove passwords, API keys, database credentials, personal information and other sensitive data before posting.

## Bug reports

Confirmed and reproducible Webteic defects should be reported through GitHub Issues after the main Webteic repository is published.

Until then, use the **Help & Support** discussion category.

## Security vulnerabilities

Do not report security vulnerabilities in public Discussions or Issues.

Until private vulnerability reporting is available in the main repository, contact Webteic privately at [support@webteic.com](mailto:support@webteic.com).

## Support expectations

Community support is provided on a best-effort basis. Response times are not guaranteed.

Support does not include managing third-party hosting accounts, accessing private servers, custom development or troubleshooting unsupported modifications.
